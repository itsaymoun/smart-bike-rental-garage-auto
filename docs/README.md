ERD files for the Smart Bike Rental database.

- `erd.drawio`: editable source (open it at (https://app.diagrams.net/#G1xhpmhZv5yY-y-C4Yi1NNx9AJtsWVAIYd#%7B%22pageId%22%3A%22erd%22%7D))
- `erd.png`: exported image (it also carries a copy of the diagram, so it can be opened in draw.io too)

If you change `erd.drawio`, re-export `erd.png` (File > Export as > PNG) and update the SQL in `schema/` so they stay the same design.
